# Contributing

This list is personal, so it is not open to pull requests. You are welcome to
fork it and build your own.

If you do spot a broken link, an entry that has moved, or a project that has
been archived, open an issue and say which line. Those reports are useful and
they get fixed.

## What an entry looks like

```markdown
- [Name](https://example.com/) - What it is, in one sentence.
```

The description starts with a capital letter and ends with a period. Entries
live in the section that fits best, and the Contents section is generated by
`make toc` rather than edited by hand.

## Running the checks

```bash
uv sync --group dev
make check
```
