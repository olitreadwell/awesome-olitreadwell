# Migration to the engine

`awesome-olitreadwell` now runs on
[awesome-list-template](https://github.com/olitreadwell/awesome-list-template).
This file records what the engine changed, what it refused to change, and what
is left for a human.

## Changed mechanically

- The heading is `# Awesome Olitreadwell`, in title case, as the conventions ask.
- `## Table of Contents` became `## Contents`, which is the heading the engine
  and awesome-lint both look for, and the block is generated by `make toc`.
- 40 entries gained a capital at the start of the description and a closing
  period. No words changed.
- Twelve entries whose link text held both a name and a description were split,
  for example `[GitHub - bendc/frontend-guidelines: Some HTML, CSS and JS best
  practices.](...)` became `[bendc/frontend-guidelines](...) - Some HTML, CSS
  and JS best practices.` Again, no words changed.
- One entry written backwards, `- Official Prettier Website - [https://prettier.io/](...)`,
  became `- [Prettier](https://prettier.io/) - The official Prettier website.`
- `Devin` said "Devin Desktop, my IDE", which repeats the item name, so the
  description is now `My IDE.`
- Every GitHub entry gained a stars and last-push segment from `make stats`.

- The five Visual Studio Code extension headings moved from level four to
  level three. awesome-lint fails a Contents section nested more than two
  levels, and the level four links would otherwise have dropped out of it.

## Left for Oli

- Eleven entries in the Visual Studio Code sections have no description. The
  engine warns about them and `tests/test_readme.py` pins the count, so the
  list cannot quietly gain more. They are the marketplace, Live Share, and
  DigitalOcean links where the title says what the thing is and only you can
  decide what to add.
- `civic-tech.md` holds about twenty bare URLs. It is a reference file, not part
  of the checked list. It either needs names and descriptions written by hand or
  it should be folded into the Civic Tech section.

## Retired

- `scripts/validate_readme.py` was replaced by the engine's rules, which are the
  same checks with tests behind them.
- `.github/workflows/ci.yml` and `.github/workflows/linkcheck.yml` were replaced
  by `.githooks/pre-push` and `jobs/links.sh`, which run on this machine without
  a hosted runner.
